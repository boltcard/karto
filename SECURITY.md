# Security

Karto holds money and keys. If you find a vulnerability, please report it privately and not in a public issue.

Use GitHub's private vulnerability reporting on this repository: the **Security** tab, then **Report a
vulnerability**. Say what is affected (Karto Wallet, Karto PoS, `cardd` or the install scripts), how to reproduce
it, and what it lets an attacker do.

Please give the maintainers time to fix it before you publish.
